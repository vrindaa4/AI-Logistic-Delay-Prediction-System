# AI-Logistic-Delay-Prediction-System
AI-powered logistics system to predict shipment delays and optimize delivery operations using ASP.NET Core, Angular, and ML APIs.

## Tech Stack
- Backend: ASP.NET Core Web API
- Frontend: Angular
- Database: SQL Server / SQLite
- AI/ML: External APIs / Python model integration

## Features
- Shipment tracking system
- Delay prediction using AI
- Real-time alerts
- Dashboard for logistics insights
